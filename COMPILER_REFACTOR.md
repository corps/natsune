# LOWERING — handoff for the backend phase (IR → nets)

This document is the handoff for the lowering phase, reconciled to the
restructured lowering (statement-per-flow sequencing, `ControlBranchFlow`,
post-hoc agent cataloging). It supersedes the phase 0–6 plan, the
declaration-layer design (§4/§5 of the previous revision — deleted), and
the absorption approach for mixed ifs (landed, then replaced — see
§8 History). Its job: carry exactly the context needed to continue — the
runtime stack, the lowering architecture, the empirical net laws, the
oracle discipline, and the next steps.

## 1. Where things stand

- **The pipeline works end to end for the supported subset:**
  `extract_source` → `analyze_signature` → `collect_symbols` →
  `collect_call_links` → `build_ir` → `lower_function`
  (`backend/lowering.py`) → `Backend.finish` → a Python callable.
  The import ban against `natsune.compiler` in frontend lowering code is
  enforced in `tests/frontend/test_link.py`.
- **The restructure** (two changes, plus cleanups):
  1. **Statement-per-flow sequencing with `ControlBranchFlow`** — each
     statement list lowers into its own `VariablesFlow` layer, sequenced
     against the containing flow; `ControlBranchFlow` owns the
     continuation/exit-path state between layers. Ifs forward all four
     result slots unconditionally; consumption is exits-driven in
     `ControlBranchFlow.close()`. Absorption is gone.
  2. **Post-hoc agent cataloging** — lowering no longer registers or
     labels agents. `run()` walks the final recorded graph, catalogs
     distinct agents into `LoweredUnit.agents`, and labeling happens
     downstream. The declaration layer (`declare_agent`/`AgentRef`/
     `NetTemplate`/`InetCallable`/registry) is deleted.
  3. Cleanups: `Graft` lost its `agent` tag (serializer tag branch
     removed); `NetTemplateBuilder` folded into `ExpansionBuilder` +
     `freeze()`/`FrozenExpansion`/`materialize_template`;
     `FlowVariableMap` → `FlowMap`; register-pair types codegen'd into
     `control_flow_generated.py`; `LegacyInetInterface` extracted to
     `legacy.py`; `IrFunction.exits` normalizes fall-through ⇒ RETURN.
- **Tests: 287 passing** — 174 frontend + 64 backend + 49 legacy.
  Snapshots: `make snapshots-check` (19).
- **Verified working** (differential vs legacy + Python semantics):
  straight-line bodies, dynamics/augassign, ifs (fall-through, all-return,
  mixed, nested, `is_it_even` verbatim), implicit-None tails, and inet
  calls through legacy-linked callees.

## 3. The lowering architecture

### 3.1 Statement-per-flow sequencing + ControlBranchFlow

Each statement list lowers into its own `VariablesFlow` layer:

- `branch_flow(body, exits)` opens a `ControlBranchFlow` over a fresh
  containing flow and lowers `body` into it; returns the containing flow.
- `lower_statements(branch_flow, body, exits)`: `flow = new_flow()`
  (`apply_new_layer()` — the fresh layer is invoked inside the containing
  flow, `internal=True`, its variables input fed from
  `cur_control.finish`); statements lower into `flow`. After an `IrIf`,
  a fresh layer begins (`flow = self.new_flow(branch_flow)`).
- `apply_continuation(invocation.wire)` merges the layer's control
  outputs back into `cur_control` — the `&`/`|`/`+`/`~` borrow/join
  choreography (wire_continuation's dance, formalized): continue/break
  borrow in/out; finish joins with the layer-input borrow; `return_value`
  unions.
- Tail (`body.closer is None` only): fall-through ⇒
  `variables_readout()` → finish readin; otherwise (every path returns)
  ⇒ `None` → return readin. `flow.close()` (slot annihilation +
  optimize) ends each layer.
- `ControlBranchFlow.close()` (context exit): shortcuts `cur_control`
  slots that `exits` says are dead, routes finish through
  `mapped_variables_readin` (usage-classified: write = feed the layer's
  value; read = pass through; neutral = erase) into the containing flow's
  finish, and forwards return/continue/break to the containing control
  outputs.

The sequencing medium is `cur_control.finish`: the layer after an
statement only receives its variables when the previous layer's finish
fires. This is what makes trailing regions correct without absorption —
the old mixed-if gating problem dissolves into layer sequencing.

### 3.2 If lowering

`lower_if`: both branches lower recursively via `branch_flow` (each with
its own `ControlBranchFlow` and `exits`); `IfThenElseStatement` composes
them; the composite is invoked on the current layer and **all four result
slots forward unconditionally** to the layer's control outputs. Slot
consumption/shortcut lives in `ControlBranchFlow.close()`, keyed on the
branch body `exits` — the IR's complete analysis replaces legacy's
flow_map-union bookkeeping.

### 3.3 Calls

`IrCallInet.ref` holds the legacy `__inet__` compiler
(`LegacyInetInterface`). `agents.callee_invocation(agent, arity,
connector)` grafts the callee, closes the callee's exceptions input and
extra interface slots, and returns (param registers, return readout).
New-lowered callees linking to each other are cutover territory;
today's linkable callee is legacy-compiled only.

**Linking caveat (pinned by a test guard):** `build_ir_for` execs a
fresh namespace, so a multi-function snippet's callee is never
`__inet__`-attached there and `collect_call_links` correctly degrades
the call to `IrDynamic` (eval fallback) — which NameErrors at runtime
against the empty eval globals. Call-case tests must link explicitly
(see `_linked_ir` in `test_lowering_oracle.py`) and assert the statement
is `IrCallInet`.

### 3.4 The post-hoc agent catalog

`run()` lowers the body, then `walk_agents(flow)` walks the recorded
graph (targets → wires → ports; `Graft.execute` descends): an
`ExpansionBuilder` is cataloged and descended, an `IfThenElseStatement`
is cataloged and its cases descended, `SerialOr`/`SerialAnd`/
`CloseAfterContingent` are cataloged, anything else raises.
`LoweredUnit(func, main: FrozenExpansion, agents, name)` is the
artifact. **Labeling the catalog is downstream work and is not yet
complete** (see §6.2).

### 3.5 The Python target

`finish` → `as_callable(func, main, executor)`: executes the frozen main
flow on a `ThreadPoolExecutor` (callee_invocation for the interface,
`filter_invocation` for the output). The output routes through a `catch`
graft — **the erasure-reveal**: a starved return delivers an `Erasure`,
which raises (exception-carrying) or `RuntimeError`s, instead of hanging
the executor. This is what made the call-path debugging tractable.
`§8.1`'s output-kind question is thereby answered for the Python target:
in-memory net objects wrapped as a callable.

## 4. Net laws (empirical — established by experiment, honored by the code)

1. **VA ingression annihilates the taken state** — chained `readin()`
   extensions on one control register cannot express alternative sources;
   the later write destroys the earlier one.
2. **SerialOr is a first-occurrence selector** — the port side firing IS
   the selection; chosen value forwarded, other side closed; a dead port
   means no selection ever happened. Intended semantics, not a quirk.
3. **Connected graft interfaces transmit dispatch structure regardless
   of values** — consuming any output slot of a connected graft
   activates it. Sequencing must therefore route through managed
   continuation (`cur_control.finish` feeding layers, `apply_continuation`
   merging); ad-hoc sibling wiring transmits structure on dead paths.
4. **Can't-fire slots are shortcut, never readout** — a readout of an
   unfired slot yields the cell's state (which flows on and drives
   whatever it feeds). `ControlBranchFlow.close()` and legacy's
   `flow_map.shortcut` exist for the same reason.
5. **`close()`/`optimize` dissolves annihilated subnets** — legacy and
   the new lowering both dissolve returning branch bodies to empty nets;
   net-shape equality only holds where structure is live.
6. **The erasure-reveal** — routing a flow's output through `catch`
   converts starved returns into raised errors; the primary debugging
   tool for "which wire starved" questions.

## 5. Oracle discipline

- **Differential execution is the primary oracle**: the program runs
  through legacy, through the new lowering, and (in the oracle suite)
  through the source's own Python semantics; all three must agree.
  Matrices: `test_if_lowering.py` (fall-through, all-return, mixed,
  nested, `is_it_even` verbatim, implicit-None) and
  `test_lowering_oracle.py` (straight-line + call cases, expected values
  derived from the source, not hand-computed).
- **Pair-equality lives at the child statement flow.** Under
  statement-per-flow sequencing, a branch body is a containing
  `ControlBranchFlow` whose statements lower into a child layer; the
  child is the statement-for-statement counterpart of legacy's branch
  flow and is pair-identical for fall-through bodies. Closing bodies
  dissolve to `[]` on BOTH sides (net law 5). The containing flow's
  machinery is new by design and has no legacy counterpart.
- **Linking guard**: call-case tests assert the statement is
  `IrCallInet` (§3.3 caveat).
- **Legacy divergences pinned** (the IR is the spec; old behavior is
  reference, not law):
  1. nested all-return ifs — legacy produces no output on the inner
     paths (wire_continuation merge starvation); ours is correct;
  2. mixed if with implicit-None tail — legacy produces no output on the
     fall-through path; ours returns None;
  3. folded unary constants — net-level only (the IR folds `-1` to
     `IrConst`; no eval machinery is recorded); behaviorally equal.
- **Not inherited from legacy**: the callee/caller variable-name
  coincidence constraint (`FlowVariableMap.update`), and the two
  starvations above.

## 6. Next steps

### 6.1 Loops (`IrWhile`/`IrFor`) — the next lowering slice

Continue/break control slots become live. Under the new model the
trailing-region question should be tractable: statements after a loop
sequence as a fresh layer off `cur_control.finish`, and the loop's
finish (= exhaustion) is exactly what should feed it — the sequencing
medium already distinguishes "loop exhausted" from "loop broke/returned"
if the Loop composite's slots are forwarded like the if composite's.
Design work remaining: the body flow's control outputs route into the
Loop composite's body-side slots (continue = re-test, break = break slot,
return = return slot); `lower_statements` must stop treating
BREAK/CONTINUE as unlowerable; the loop's test/iter plumbing mirrors
`lower_if`'s test wiring. Legacy's `Loop` usage in `compiler.py`
(parse_statement_body's For/While branch) is the behavioral reference.

### 6.2 Agent labeling (post-hoc) — downstream, incomplete

The catalog exists (`LoweredUnit.agents`); recovering stable labels from
it is not done. Requirements: deterministic names (the IR already uses
`__natsune_N__` placeholders), stable across runs for cross-module
linking, and enough structure (which graft is which if/call) for the
emitter and for diagnostics. Likely home: a labeling pass over the
recorded graph in the compiler proper, not in lowering.

### 6.3 Cutover checklist (accumulated TODOs)

- `FlowMap` removal: `ControlBranchFlow` carries two TODOs — its
  `variables_usage` mapping should take the name→usage dict directly and
  `mapped_variables_readin`/`variables_readout` should drop the
  legacy-shaped map.
- File positioning: `VariablesFlow` and `ControlBranchFlow` are
  conceptually lowering constructs; reconsider their home when the old
  compiler dies (control_branch_flow.py TODO).
- `IrBreak`/`IrContinue` lowering lands with loops (§6.1).
- New-lowered callee linking (call a restructured function from another)
  — today only legacy callees link.
- Re-point the snapshot oracle at all of `tests/frontend/programs.py`
  (delayed_inverse and the infinite-loop programs may need special
  handling).
- `IrStructureError` at build → `DiagnosticSink` diagnostic? (analysis-
  style consistency question; not urgent).
- try/except\*: still rejected outright; the exceptions register is
  threaded through every layer, but no capture machinery exists yet —
  at minimum a stub story is needed when IrTry lands.

### 6.4 CppBackend notes (deferred until the above settles)

`LoweredUnit.agents` is the emission inventory; statement-per-flow
layering multiplies recorded nets (one per statement list) — acceptable
for the Python runtime, worth measuring for emitted code size.
`materialize_dynamic` is Python-only by contract (emitters refuse and
require natsune-compiled callees — §8.4 resolved). Constants enter nets
as recorded `ConstantValuePort`s; how an emitter serializes them remains
open.

## 7. Open questions (remaining)

1. **Loop trailing-region details** — beyond §6.1's sketch: break-slot
   wiring into `cur_control.break`, orelse sequencing, and whether
   `apply_continuation`'s borrow/join handles the Loop composite's slots
   unchanged.
2. **Constants for the emitter** — `Any`-typed `ConstantValuePort` vs
   serializable constants; purely an emitter question (§6.4).
3. **`IrStructureError` → `DiagnosticSink`** — analysis-style
   consistency; not urgent.
4. **try/except\*** — rejected outright; revisit only with a lowering
   design for exception capture.

## 8. History (superseded designs, kept for memory)

- **The declaration layer** (previous revision §4/§5: `AgentDef`,
  `AgentRef`, `declare_agent`/`resolve_call`/`agent_def`, the
  `InetCallable | NetTemplate | Primitive` union, `runtime.py`,
  `types.py`) — deleted. Replaced by the post-hoc catalog (§3.4); the
  vocabulary survives as `AgentImpl = ExpansionBuilder |
  LegacyInetInterface | IfThenElseStatement`. Naming decisions that
  still hold: the verb is `lower`/`lowering`; the protocol type is
  `Backend` (`ports.Target` is taken).
- **Absorption** (`_lower_absorbing_if`) — landed for mixed ifs, then
  replaced by `ControlBranchFlow` sequencing in the restructure. The
  mixed-if differential coverage carried over unchanged.
- **Slice-era slot consumption in lowering** (slice 1/2: conditional
  return/finish consumption keyed on per-branch exits inside
  `_lower_if`) — replaced by unconditional forwarding +
  `ControlBranchFlow.close()`'s exits-driven shortcuts. The rule "can't-
  fire slots are shortcut, never readout" (§4.4) survives in
  `close()`.
- **Legacy bug record** (found while building the oracle; the IR is the
  spec): nested all-return ifs and mixed-if-with-implicit-None-tail both
  starve in legacy's `wire_continuation` (no output on the affected
  paths); both lower correctly here. The callee/caller variable-name
  coincidence constraint is not inherited.
